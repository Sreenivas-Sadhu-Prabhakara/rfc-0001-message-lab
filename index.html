Read RFC 1 ↗Status & errata ↗

RFC 1 sketches a 16-bit header with destination, link, trace and spare fields. Its message-body limit is 8,080 bits. The link field has room for 256 values, while the proposal describes 32 links, including link 0 for control.

A classroom can turn an abstract network diagram into something inspectable. Change a field, watch its bits, and discuss why the destination and the payload are separate.

Educational representation of a 1969 proposal. The displayed bit order is our visual convention. UTF-8 input is modern. This tool does not send packets or implement the ARPANET wire protocol. Official index status: UNKNOWN (Legacy stream). This project is independent of the RFC Editor and IETF.

Try it with someone

A two-minute experiment

Set the destination to 31, then try 32. Try link 32. Why is one out of range while the other fits its field? Finally paste an emoji and compare bytes with visible characters.
