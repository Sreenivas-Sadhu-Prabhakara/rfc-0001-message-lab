## Community post

We are turning the RFC series into small, useful learning tools. This edition explores RFC 1, a legacy Host Software proposal, through Message Lab. Inspect destination, link and trace fields; measure UTF-8 text against the historical message-body limit. Educational representation of a 1969 proposal. The displayed bit order is our visual convention. UTF-8 input is modern. This tool does not send packets or implement the ARPANET wire protocol.

Try it: https://sreenivas-sadhu-prabhakara.github.io/rfc-0001-message-lab/
Source and contributions: https://github.com/Sreenivas-Sadhu-Prabhakara/rfc-0001-message-lab
Original document: https://www.rfc-editor.org/rfc/rfc1.txt

## Teaching exercise

Set the destination to 31, then try 32. Try link 32. Why is one out of range while the other fits its field? Finally paste an emoji and compare bytes with visible characters.
